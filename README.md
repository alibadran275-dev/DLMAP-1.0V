# DLMap v2.0 - Enterprise Static Analysis Tool\n\n**DLMap** (Deep Logic Map) is a professional-grade static analysis security tool designed to scan mobile applications, source code, and archives for security vulnerabilities and misconfigurations.\n\n## ✨ Key Features\n\n- **🚀 High Performance**: Multi-threaded scanning with configurable worker threads\n- **🧠 Intelligent Analysis**: Cognitive context analyzer to reduce false positives\n- **📊 Comprehensive Coverage**: 30+ security rules mapped to OWASP MASVS, CWE, and CVSS standards\n- **🔐 Sensitive Data Protection**: Automatic masking of secrets and credentials in reports\n- **📦 Archive Support**: Handles APK, ZIP, TAR, and other archive formats\n- **📈 Multiple Report Formats**: CLI, JSON, and beautiful HTML dashboards\n- **🎯 Precise Detection**: Advanced entropy analysis for encrypted/encoded data detection\n- **🔧 Extensible Architecture**: Easy to add new rules and custom analyzers\n\n## 📋 Supported File Types\n\n- **Mobile**: AndroidManifest.xml, APK files\n- **Source Code**: Java, Kotlin, Swift, JavaScript, TypeScript, Python, Go, Rust, C/C++\n- **Configuration**: XML, JSON, YAML, Properties, Gradle, Plist\n- **Archives**: ZIP, APK, AAR, JAR, TAR, TAR.GZ\n\n## 🛡️ Security Rules Coverage\n\n### Manifest Analysis (5 rules)\n- Debug mode detection\n- Backup configuration weaknesses\n- Cleartext traffic exposure\n- Low SDK version targeting\n- Exported component protection\n\n### Code Analysis (14 rules)\n- Hardcoded AWS credentials\n- Google API key exposure\n- Stripe secret key leaks\n- GitHub token exposure\n- Slack token exposure\n- Weak cryptographic hashes (MD5, SHA-1)\n- Insecure cipher modes (AES-ECB)\n- SQL injection vulnerabilities\n- World-readable/writable file permissions\n- Hardcoded encryption keys\n- Insecure random number generation\n- Command injection vulnerabilities\n\n## 🚀 Quick Start\n\n### Installation\n\n```bash\n# Clone or download the project\ncd dlmap_v2.0\n\n# Make main script executable\nchmod +x dlmap.py\n```\n\n### Basic Usage\n\n```bash\n# Scan a directory\npython3 dlmap.py -A ./target_directory\n\n# Scan an APK file\npython3 dlmap.py -A ./app.apk\n\n# Scan with custom thread count\npython3 dlmap.py -A ./target_directory -t 16\n\n# Generate HTML report\npython3 dlmap.py -A ./target_directory --html report.html\n\n# Generate JSON report\npython3 dlmap.py -A ./target_directory --json report.json\n\n# Show detailed findings\npython3 dlmap.py -A ./target_directory --detailed\n```\n\n## 📊 Report Types\n\n### CLI Report (Default)\n```\n================================================================================\nDLMap v2.0 - Enterprise Static Analysis Tool\n================================================================================\n\nFiles Scanned: 15\nTotal Findings: 23\nRisk Breakdown:\n  INFO: 2\n  LOW: 0\n  MEDIUM: 8\n  HIGH: 10\n  CRITICAL: 3\n```\n\n### HTML Report\nBeautiful interactive dashboard with:\n- Risk summary cards\n- Detailed findings with remediation\n- Compliance mapping (MASVS, CWE, CVSS)\n- Color-coded risk levels\n\n### JSON Report\nStructured output for integration with:\n- CI/CD pipelines\n- SIEM systems\n- Security dashboards\n- Automated workflows\n\n## 🏗️ Project Structure\n\n```\ndlmap_v2.0/\n├── `config.py` to customize:\n\n```python\nSCAN_CONFIG = {\n    \"default_threads\": 8,                    # Thread pool size\n    \"max_file_size_bytes\": 50 * 1024 * 1024, # Max file size\n    \"timeout_per_file\": 30,                  # Timeout per file\n    \"supported_extensions\": {...},           # File types to scan\n    \"ignored_directories\": {...},            # Directories to skip\n}\n```\n\n## 🎯 Risk Levels\n\n| Level | Description | Action |\n|-------|-------------|--------|\n| **CRITICAL** | Immediate security risk | Fix immediately |\n| **HIGH** | Significant vulnerability | Fix urgently |\n| **MEDIUM** | Moderate risk | Fix in next sprint |\n| **LOW** | Minor issue | Consider fixing |\n| **INFO** | Informational | Review and document |\n\n## 📚 Compliance Standards\n\n- **OWASP MASVS**: Mobile Application Security Verification Standard\n- **CWE**: Common Weakness Enumeration\n- **CVSS**: Common Vulnerability Scoring System\n\n## 🔍 Advanced Features\n\n### Cognitive Context Analysis\nReduces false positives by analyzing surrounding code context:\n- Detects production vs. test/mock code\n- Escalates risk for production credentials\n- De-escalates risk for test data\n\n### Entropy Analysis\nDetects potential encrypted/encoded data:\n- Shannon entropy calculation\n- High-entropy token identification\n- Binary file string extraction\n\n### Sensitive Data Masking\nProtects credentials in reports:\n- Shows only first and last 6 characters\n- Masks API keys, tokens, and passwords\n- Customizable masking rules\n\n## 📈 Performance\n\n- **Scanning Speed**: ~100 files/second (varies by file size and complexity)\n- **Memory Usage**: Minimal, streaming-based processing\n- **Scalability**: Linear scaling with thread count\n\n## 🤝 Contributing\n\nContributions are welcome!
